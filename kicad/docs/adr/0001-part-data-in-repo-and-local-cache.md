# ADR 0001: Part data in the repository and in a local cache

- **Status:** Superseded: moved to [parts-lib ADR 0001](https://github.com/opendap-project/parts-lib/blob/main/docs/adr/0001-part-data-in-repo-and-local-cache.md), where tool-independent part data now lives
- **Date:** 2026-10-22

## Context

Every part in the BOMs needs data for design and simulation: datasheets, PCB footprints, symbols, 3D models, and electrical, electromagnetic, thermal and mechanical simulation models. Much of what manufacturers publish cannot be redistributed, and this repository is public under CERN-OHL-W-2.0.

## Decision

- **In the repository** (OpenDAP's own work, under this repository's licences):
  - symbols and footprints drawn from the datasheets, following KiCad's library conventions;
  - 3D models generated by OpenDAP from the datasheet dimensions (scripted, so they are reproducible);
  - one spec sheet per part, `parts/<manufacturer>/<MPN>.md`, transcribing the data the project needs;
  - the manifest `parts/manifest.toml`, listing every external file with its official URL, revision, date and sha256.
- **In a local cache** (`~/.cache/opendap/parts/`, never committed) unless the file's licence explicitly allows redistribution: datasheets, manufacturer STEP models, IBIS and SPICE models, S-parameter (Touchstone) files and other vendor files. They are fetched from the official URLs in the manifest and verified against their sha256.
- When a manufacturer licence allows redistribution, the file may be committed, with its licence recorded in `REUSE.toml`.
