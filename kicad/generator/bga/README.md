# BGA parts

Data for `generator/bga.py`, which builds the BGA parts of this library: the RK3566 SoC (`rockchip/`), the K4UBE3D4AB-MGCL LPDDR4X and the KLMBG2JETD-B041 / KLMAG1JETD-B041 eMMC (`samsung/`), and the MT53E1G32D2FW-046 LPDDR4X (`micron/`), whose land also takes the CXMT CXDB5CBAM-MA-B second source (T1 board ADR 0022). The data files are the reviewed source; the symbols, footprints and STEP models are generated from them and never edited by hand.

## Use

```sh
python3 generator/bga.py            # symbols/<Library>.kicad_sym, footprints/<Library>.pretty/, *.model.json
KIGEN_ROOT=$PWD /Applications/FreeCAD.app/Contents/Resources/bin/freecadcmd generator/bga_model.py
                                    # 3dmodels/<Library>.3dshapes/<footprint>.step
python3 generator/test_bga.py       # the second reading below
python3 generator/bga.py --check    # exits 1 if a generated file is stale
```

Python 3.11 or later (`tomllib`). Optional: `pdfplumber` and the datasheets in the local parts cache (`~/.cache/opendap/parts/`, parts-lib `manifest.toml`) for the PDF re-extraction; KiCad 10 for the load check.

## Files per part

| File | What it holds | Source |
|---|---|---|
| `<Part>.toml` | Package dimensions, the ball grids (`[[grid]]`, used by the generator), the drawing's primary dimensions (`[[drawing]]`, used only by the test), the land, the symbol units and pin types, the checks | Each value cites the datasheet page |
| `<Part>-pins.csv` | Every ball: ball number, pad name verbatim, IO power domain where the datasheet gives one, page | The datasheet's pin list table |
| `<Part>-ballmap.txt` | The ball-map figure transcribed cell by cell (`o` ball, `-` no ball) | The datasheet's ball-map figure |

## Second reading (`test_bga.py`)

The test does not import the generator and does not read `[[grid]]`. It parses the committed `.kicad_mod` and `.kicad_sym` files and checks them against the other transcriptions of the same datasheet:

- the ball set four ways: ball-map figure, pin-list table, footprint pads, symbol pin numbers; and the count the datasheet states;
- every pad centre recomputed from the drawing's primary dimensions (body, edge-to-first-ball distances, spans, pitch) with JEDEC row letters generated by the test;
- every symbol pin name against the pin list, valid pin types, no hidden pins, alternates equal to the pad name's functions, the fields Reference, Value, Footprint, Datasheet, Description, Manufacturer and MPN;
- the land against the prototype fab's limits: BGA pad ≥ 0.25 mm, copper gap ≥ 0.065 mm, mask web ≥ 3 mil;
- where available, the pin list re-extracted from the datasheet PDF itself (`pdf_ballout_cols` when the ballout figure prints no cell for empty columns) and, for the RK3566, the pad names of the T1 board's `hardware/pinout/pinout-v1.csv`.

A moved pad (20 µm) or a renamed pad makes the test fail.

## RK3566 land pattern

Rockchip publishes no land pattern (RK3566 Datasheet Rev 1.1, pp. 21–22 give the package drawing only). The land is derived here:

- **Size: 0.25 mm copper on both grids.** IPC-7351B sizes BGA lands below the ball for collapsing balls, about 20 % for small balls, which gives 0.20 mm for the 0.25 mm nominal ball (DS p. 22: b 0.200 / 0.250 / 0.300 mm). The IPC table itself was not retrieved: **UNVERIFIED**; KiCad's own library uses 0.20 mm NSMD pads for 0.25 mm balls at 0.4 mm pitch (`BGA-81_…_P0.4mm_Ball0.25mm_Pad0.2mm_NSMD`), consistent with it. the prototype fab's prototype factory asks for a BGA pad of at least 0.25 mm (0.20 mm at the advanced factory) [P10], and the PCBWay HDI rule set asserts 0.25 mm. The land is therefore 0.25 mm: the fab's minimum, equal to the nominal ball.
- **NSMD, not SMD.** At 0.4 mm pitch a 0.25 mm NSMD land leaves 0.15 mm of copper gap; an SMD land (0.30 mm copper, 0.25 mm opening) would leave 0.10 mm. The extra copper gap is what the escape uses: one 0.08 mm track through an outer-row gap and the laser-microvia dog-bones into the 0.825–0.875 mm channel between the ring and the core. The cost is the mask web: NSMD gives 0.099 mm (3.9 mil) between ring lands, at the prototype fab's 3 mil advanced green web [P2] and below the 4 mil normal one [P3]; SMD would give 0.15 mm. The general reliability argument for NSMD (IPC-7095) was not retrieved: **UNVERIFIED**.
- **Mask: 1 mil (0.0254 mm) per side, opening 0.3008 mm**, the prototype fab's minimum mask opening in BGA areas [P1].
- **Paste: 1:1** with the land. The stencil is a fab-package decision.

[P1], [P2], [P3], [P10] are the fab capability pages listed in [`design-rules/pcbway-capabilities.md`](../../design-rules/pcbway-capabilities.md).

The memory parts follow the same policy; their choices are written in their `.toml` files. The Micron land (0.30 mm NSMD) is sized for two ball diameters, Micron's 0.436 mm and CXMT's 0.31 mm, on one footprint whose body is the envelope of both packages.
