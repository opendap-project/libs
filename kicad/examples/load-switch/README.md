# Example: load-switch block

A small KiCad 10 project that applies §9 of the [PCB craft standard](../../docs/specs/pcb-craft-standard.md) end to end and passes every schematic check of `odapkit craft check` at Q4, with no ERC violation. Generated by [`templates/generate.py`](../../templates/generate.py).

| Page | Sheet | Shows |
|---|---|---|
| 1 | `load-switch.kicad_sch` | Root: overviews first, blocks in signal-flow order, wired through sheet pins; rails as power symbols |
| 2 | `power.kicad_sch` | Power overview: power tree and rail table |
| 3 | `interconnect.kicad_sch` | Interconnect overview: J201 pin map |
| 4 | `header.kicad_sch` | `blk.header`: the input connector and the host-side pull-down that sets the switch block's absent state |
| 5 | `periph-switch.kicad_sch` | `blk.periph-switch`: a TPS22919 load switch with a measurement link and Kelvin pads, titled groups, interface and rail tables, notes |

The project carries its own `sym-lib-table` and `fp-lib-table` (KiCad's stock libraries through `${KICAD10_SYMBOL_DIR}` and `${KICAD10_FOOTPRINT_DIR}`, the example's symbol in `example.kicad_sym`), so it checks the same way on any machine. `load-switch.craft.toml` holds the check's configuration: target level, rails, net classes and block interfaces.

```sh
odapkit craft check examples/load-switch/load-switch.kicad_sch
```

Part numbers and data-sheet links are illustrative and were not checked against stock.
