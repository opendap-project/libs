# Blender assets requirements

| ID | Requirement | Priority | Status |
|---|---|---|---|
| BLIB-001 | OpenDAP shall maintain its own Blender asset library, shared by every OpenDAP render. | must | Confirmed |
| BLIB-002 | Assets that belong to the OpenDAP project shall be CC-BY-SA-4.0; generic assets that enable others to innovate shall be CC-BY-4.0. | must | Confirmed |
